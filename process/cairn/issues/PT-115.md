## Comments

### @team-lead — 2026-09-08

Architect's carry-forward from PT-113's verdict @58d22af (2026-09-09): `_test_run_shared.is_test_invocation` anchors on the interpreter token being immediately adjacent to the script/module token, so `python3 -X dev scripts/cairn/run_tests.py --gate green` and `uv run scripts/cairn/run_tests.py …` are not recognised — the guard lets an un-tiered full run through and the record hook does not patch `who`. Fix: allow interpreter flags between the two tokens (`-X …`, `-W …`, `-u`, `-B`), and treat `uv run` / `poetry run` as launcher prefixes; truth-table tests both directions incl. the `git add python3.14` false-positive control. Backlog (filed during the PT-0.12.2 backlog drive; Mosko routes).
