The dashboard's foundation: a **real shadcn-svelte app** (ruled 2026-08-26,
Mosko — see TEMPLATE_DECISIONS.md) using actual Components/Blocks/Charts,
served by the cairn board server, rendering real repo state. The vanilla
zero-build principle stays for the existing board; the dashboard is where
the template dogfoods the stack downstream projects will use.

**Acceptance criteria**
- [ ] Svelte + Tailwind + shadcn-svelte app scaffolded (location per
      architect ruling, e.g. `apps/dashboard/`), preset `b6XadDxmQS` tokens
      as the app.css `:root`/`.dark` blocks exactly per
      `design-system-spec.md`; `docs/DESIGN/tokens.css` ships as the same
      blocks (reference deliverable)
- [ ] Dashboard page composed from real shadcn-svelte components (Card,
      Badge, Button, Table; a dashboard Block as the layout starting
      point), styled at the spec's Dashboard scale
- [ ] Fonts self-hosted (e.g. Fontsource) — no CDN at runtime; architect
      confirms
- [ ] Board server serves the built app at `/dashboard`; a
      `/api/dashboard` payload carries real data: current branch +
      clean/dirty (git), latest tag + release row, tracker counts by
      status (engine), `cairn check` result — server-side only
- [ ] Build-output policy ruled by architect (committed dist vs on-demand
      build) and documented
- [ ] Tests cover the payload endpoint (py harness) and the app's build
      (smoke: built entry exists / renders)
