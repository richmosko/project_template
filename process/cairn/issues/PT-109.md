## Comments

### @team-lead — 2026-09-08

Found closing PT-0.12.1 (2026-09-08), the first `cairn archive` since PT-94 E15 landed. `cmd_guard_commit` runs `git diff --cached -- <rel>` without rename detection, so a moved issue (`issues/X.md → archive/issues/X.md`) diffs as 100 % added lines and every historical comment author counts as "someone else's uncommitted hunk" — 16 refusals on the archive commit, all false. The commit was made with `--no-verify` after confirming `git diff --cached -M --name-status` showed pure renames (R100).

Fix: run the cached diff with `-M` (or `--find-renames`) and skip `R` entries whose similarity is 100 %; for partial renames diff against the rename source. One regression test: stage a rename of a multi-author issue into `archive/issues/` and assert guard-commit returns 0. Same defect class as archive's own precondition note at cairn.py ~L215.
