## Problem

PT-86's self-stop (session registry drains non-empty → empty, grace window elapses, final flush,
pidfile removed, exit) writes nothing to `process/cairn/metrics/otel_receiver.log`. On 2026-09-04
an unexpected receiver exit looked like a new defect and cost a diagnosis round (PT-84 comments
6304afd, e1e9cd4): the log held only an earlier refused-flush line, and the self-stop left no trace.

## Ask

One log line at the point of no return, naming the trigger: `self-stop: registry drained at
<ts>, grace <n>s elapsed, flushed <k> lines, exiting`. Also one line when a registration cancels an
armed grace window. Nothing else changes.

1. Test: the existing self-stop test asserts the log line is present with the trigger named.
2. Test: the cancel-inside-grace test asserts the cancel line.
