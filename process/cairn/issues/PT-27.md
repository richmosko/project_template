Convention change (Mosko, 2026-08-21, confirmed reading): definition-only
milestones — PRD/Research, ARCH+SECURITY/Plan — use letter ids `A`, `B`, `C`…;
`M0`, `M1`, `M2`… are reserved for actual development milestones. A fresh
project therefore bootstraps with `A` (Bootstrap & Research) and `B` (Plan)
instead of today's `M0`/`M1`, and its first development milestone becomes `M0`.

## Acceptance criteria

- [x] `check_repo` lints id-shape ↔ kind consistency (a letter id with `kind: product`, or an `M<n>` id with `kind: process`, is an error). Existing-repo grandfathering ruled by the architect and recorded.
- [x] Verified nothing else keys off the `M` prefix (engine sort, board swimlanes/tabs, /drive, WORKFLOW.md references) — fix or document anything found.
