Found during PT-17 acceptance (2026-08-20): TaskCreate/TaskGet/TaskList/TaskUpdate
are session-gated — absent from teammate tool sets in this environment even when
explicitly allowlisted. WORKFLOW.md's Team-coordination section builds on the
anchor-task pattern (shared task list, blockedBy chains), which silently cannot
operate in such sessions. Fix is documentation + graceful degradation: state the
session requirement, and codify the proven fallback (lead-mediated dispatch via
SendMessage + temp/ hand-off files) as the pattern's degraded mode rather than an
improvisation. Verify Task-tool availability mechanics against current docs at
implementation time.
