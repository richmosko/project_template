## Comments

### @team-lead — 2026-09-08

Found on PT-92 finish-feature pre-flight (2026-09-08). `scripts/cairn/cairn loop-stats PT-92` raises `TypeError: expected string or bytes-like object, got 'dict'` at `loop_stats.py:344` (`_CONFIRM_RE.search(body)`). Cause: `audit_agent` reads `inp.get("message")` from SendMessage tool calls and assumes a string; the shutdown/plan-approval protocol messages carry a JSON object (`{"type":"shutdown_response",...}`), so any loop whose window contains a team teardown crashes the scorecard.

Fix: coerce a non-string body (`json.dumps`) or skip protocol messages entirely (they are not prose and should not count toward CONFIRM_ROUNDTRIP / long-message flags); one regression test with a dict-bodied SendMessage record in a fixture transcript. Workaround used on PT-92: `--transcripts-dir <empty dir>` (scorecard without the transcript cross-check).
