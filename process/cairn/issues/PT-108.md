### @architect — 2026-09-08

**Ruling (gate 1).** Skip protocol messages; coerce every other non-string. Reproduced both crash sites by construction (`audit_agent` over a one-record fixture, body `{"type":"shutdown_response","request_id":"r1","approve":true}`):

| SendMessage input | result |
|---|---|
| dict body **+** `summary` | `TypeError: ... got 'dict'` at loop_stats.py:344 |
| dict body, **no** `summary` | `KeyError: slice(None, 90, None)` at loop_stats.py:343 |
| string body (control) | no crash; messages=1, msgs_to_lead=1 |

The brief names :344 only. `detail = (inp.get("summary") or body)[:90]` on :343 crashes first whenever `summary` is absent, so **the guard must sit above `detail`** — a fix at the regex leaves the second branch live.

**Seam** — `loop_stats.audit_agent`, `elif cls == "message":`, as the branch's first statement. Add a module-level `_message_body(inp) -> Optional[str]`:
- `str` → return unchanged.
- `dict` whose `.get("type")` ∈ {`shutdown_request`, `shutdown_response`, `plan_approval_request`, `plan_approval_response`} → `None` (protocol).
- any other non-string (dict with absent/unknown `type`, list, int) → `json.dumps(body, sort_keys=True)`. Fail toward counting: a real message must never be dropped from the accounting silently.

`None` ⇒ emit the step under class **`message_protocol`**, detail `→<to>: <type>`, no flags, no `msgs.append`. Protocol bodies are a machine handshake, not prose: they must not reach CONFIRM_ROUNDTRIP, `long(N lines)`, `messages`, `msg_lines_total`, or `msgs_to_lead` — the last is a budget cap (`DEFAULT_CAPS` 40), and a teardown handshake inflating a budget is the same defect class as the crash. A distinct class rather than reusing `"message"` keeps `by_class["message"] == summary["messages"]`; nothing enumerates class strings exhaustively (`classify` already returns open-ended `"other:"+name`; the scorecard renders tool_calls / full_suite_runs / msgs_to_lead / waste, not `by_class`). The row still counts as one tool call — the call happened.

**Guards (qa, gate 2)** — `scripts/cairn/tests/test_loop_stats.py`, `AuditAgentTests`, one dict-bodied record per case:
1. protocol dict **with** `summary` → no exception; `messages == msgs_to_lead == msg_lines_total == 0`; exactly one step of class `message_protocol`. (Mutation: drop the skip → CONFIRM/long flags and msgs_to_lead return.)
2. protocol dict **without** `summary` → no exception. Both cases are required; case 1 never reaches :343.
3. non-protocol dict (e.g. `{"note": "..."}`) → no exception and `messages == 1`. (Mutation: skip every dict → 0; proves coerce, not drop.)
4. string body stays the control — existing test at :147 must remain green unedited.

**Scope** — `loop_stats.py` + `test_loop_stats.py` only; no CLI or flag change. `lead_inbound` is out of scope: its bodies come from rendered transcript text and are already `str` (line 394 path).

Open questions: none.
