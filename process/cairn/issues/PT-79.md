## Problem

Once PT-77 and PT-78 populate the shared data file, nothing shows it.

## Acceptance criteria

1. The board serves the data file on an API path. The dashboard gets a new block beside the
   PT-61 chart: one bar per issue (plus `main`), stacked by role.
2. Toggle between **tokens** and **estimated cost**. In tokens view, input and output are
   separate series; cache read and cache write are distinguishable from fresh input.
3. Cost uses a dated, checked-in price table per model (input, cache write, cache read, output,
   $/MTok). The block is labelled "estimated"; tokens are not.
4. The issue drawer shows the issue's totals with the role split.
5. Existing dashboard tests extend to the block; a browser-visibility check per the PT-32/PT-57
   protocol, not property reads.
6. `process/TRACKER.md` documents the price table and where to update it.
