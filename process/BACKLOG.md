# Backlog — deprecated stub

> **This file is retired.** The overflow queue existed only because Linear's free tier capped active issues at 250. The tracker is now **cairn** ([`TRACKER.md`](TRACKER.md)) — no cap, no tiers: a scoped-but-not-started item is simply an issue with `status: backlog`.
>
> - **Jot a rough item:** `scripts/cairn/cairn new "<title>" --status backlog` (add `--milestone <m>` if known)
> - **See the queue:** the board's Backlog column (`/cairn`), or `scripts/cairn/cairn ls --status backlog`
> - **Migrating a legacy project?** `/setup-tracker` step 5 imports this file's rows as backlog issues, then reduces it to this stub.
>
> This stub is kept one release for link stability, then deleted.
